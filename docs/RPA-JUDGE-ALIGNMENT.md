# example-agent 裁判初始化对齐记录

完成日期：2026-09-12。

原迁移脚本没有读取 RPA 的 `config/current_judge.json`，而是创建硬编码的
`pairwise_llm + doubao-seed-2.1-turbo` 裁判。这不是已采用的 RPA 裁判。

当前生产与开发裁判均为 **j-0005**，初始化来源为
`judge-82c00309727a90a9`（`judge_single_rule_full_timeline_v1`）。

| 项目 | 对齐结果 |
| --- | --- |
| 通道 | Codex CLI 0.144.1 |
| 模型 / 推理 / 超时 | gpt-5.6-luna / low / 360 秒 |
| 判定方式 | 大模型先判断 A/B，再提取布尔特征，用冻结 LR 校正 |
| 校正模型 | symmetric_logistic_refined_boolean_crosses，524 维，无截距 |
| 改判条件 | 校正器与初判不同，且校正器置信度 ≥ 0.7 |
| 资产 | 原始配置、规则、参考资料、完整校正模型逐字复制并校验 SHA-256 |
| 运行依赖 | 本项目内的纯推理代码和 Judge 版本资产；不读取 RPA 目录 |

原 d-0001 的 case 缺少本人角色、时间和来源聊天 ID。已逐题依据原始导出核对，
生成 d-0002 补齐元数据。开发 1,000 题和固定 1,000 题的 ID、正文、答案、
顺序、分集均不变，风格池、人设和生成器指针不变。旧数据和旧实验仍保留。
切换前的指针保存在 `instances/example-agent/pointers.before-j-0005.json`。

验证：

- 60 项单元测试通过，覆盖 A/B 映射、0.7 阈值边界、格式重试、资产损坏、快照继承和来源核对。
- 43 个推理定义与 RPA 来源 AST 一致。
- 使用真实 524 维权重做 200 组原实现/移植实现对照，最大概率差为 0。
- 构建后的提示词与 RPA 原函数输出逐字一致。
- 私聊、群聊各一次实际 Codex 合成样本检查成功，均完整执行初判和特征提取。
  这是连通性验证，不是模型效果评测，也未重跑固定集。
- 重复执行 `--judge-only --adopt` 确认幂等；后台来源与规则可在页面内展开。
